## 威胁（STRIDE 速查）

| 类别 | 自查问题 |
|---|---|
| 伪装 | 攻击者能冒充用户或服务吗？ |
| 篡改 | 输入或存储数据能被悄悄改掉吗？ |
| 否认 | 出事后能查到是谁干的吗？ |
| 信息泄漏 | 敏感数据暴露给了谁？ |
| 拒绝服务 | 耗尽资源最便宜的方式是什么？ |
| 权限提升 | 低权限调用者能摸到管理操作吗？ |
## 常见威胁示例（照此格式补充本项目的）

| 威胁 | STRIDE | 缓解措施 | 状态 |
|---|---|---|---|
| 搜索框 SQL 注入 | 篡改 | 只用参数化查询；用 ORM，禁止字符串拼接 SQL | ✅ |
| 登录后会话固定 | 伪装 | 权限变化时轮换会话 ID；Cookie 设 HttpOnly + Secure | ✅ |
| 详细报错页泄漏堆栈 | 信息泄漏 | 给客户端通用信息，详情只进日志 | ❌ |
| 无限制文件上传 | 拒绝服务 | 大小 + 类型白名单；处理前先扫描 | ❌ |
| 管理操作无审计日志 | 否认 | 追加式审计日志（操作人 + 时间戳） | ❌ |

> ✅ = 已缓解且有测试，❌ = 接受的风险（必须有负责人 + 到期时间）或已建 issue。任何行都不许没有状态。
