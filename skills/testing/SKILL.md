# Testing（测试）

## 适用场景

行为变更时：写测试、跑全量、定位失败。

## 执行步骤

1. 运行技术栈测试命令：`pnpm test`
2. 新行为必须有新测试——逻辑用单元测试，边界用集成测试。
3. 失败时：先复现，再修复，然后跑全量（不只跑失败的那个）。
4. 覆盖变化时更新 `docs/testing/test-matrix.md`。

## 验证要求

- 给出测试运行输出（通过数、失败数），最终代码必须全绿。

## 完成标准

- 全量测试通过，且测试矩阵与实际一致。
